"Hello everyone! Welcome to my demonstration of the AI-Powered Personal Finance Advisor Bot.

In today's fast-paced world, managing personal finances is a common challenge. Most traditional budgeting apps act as passive digital ledger sheets—they record your numbers, but they don't give you personalized, actionable advice on how to improve your financial habits.

⏱️ [0:45 - 1:30] 2. ARCHITECTURE & TECH STACK (45s)
-------------------------------------------------------------
[ACTION: Show Architecture Diagram: User -> Flask -> DB -> LLM Engine]

"Let's take a quick look at the technical architecture behind the application:

• Backend: Built on Python using the Flask web framework, structured using modular blueprints for Authentication, Financial Tracking, and AI Services.
• Database & ORM: Powered by SQLAlchemy with an SQLite database, managing structured relational models for Users, Transactions, and Budgets.
• Security: Features secure session management via Flask-Login, industry-standard password hashing using Bcrypt, and secure credential handling via environment variables.
• Frontend: Responsive and modern UI built with Jinja2 templates, Bootstrap 5, and dynamic markdown parsing with Marked.js.
• AI Engine: Integrated with Generative AI LLM APIs to perform real-time financial health evaluation and budget generation."
