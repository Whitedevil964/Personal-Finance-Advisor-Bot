2. Architecture & Technical Workflow
🖥️ On Screen: Switch to architecture_slide.html (Full-Screen). Point your mouse cursor to each box as you mention it.
"Here is the high-level system architecture of the platform:

• Flask Framework: The core backend is built with Python and Flask, organized cleanly into modular blueprints for Authentication, Transactions, Dashboard, and AI Services.
• User Input & Financial Tracking: Users log their income streams, day-to-day expenses, and custom categories.
• Database & ORM: Managed using SQLAlchemy with SQLite for structured, secure relational storage of users, transactions, and budgets.
• Generative AI Integration: Integrates directly with LLM APIs to perform intelligent prompt engineering on the user's spending data.
• Automated Outputs: The AI generates dynamic budget plans, tailored saving suggestions, and monthly health reports.
• Security: Complete credential isolation using .env files, session management via Flask-Login, and password hashing using Bcrypt."
